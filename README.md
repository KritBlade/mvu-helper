# MVU Helper template

This branch is the starting workspace for building your own game on MVU Helper. Clone it, run `npm run dev`, and turn on the Artifact dev loop in MVU Helper. From then on, every file you or your AI saves in `workspace/` lands on the open SillyTavern card a second later. It comes with ArtificKoi's game logic, status menu and an event pack to learn from, 2 sample plugins, a `CLAUDE.md` with the rules your AI needs, and a `.mcp.json` so your AI can see Chrome. How to set it all up is on [Development Environment and Dev Loops](https://github.com/KritBlade/mvu-helper/blob/main/doc/dev_env/README.md).

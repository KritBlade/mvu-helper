Registration

How a new character gets on file, and where the cast lives in stat_data.

Where looks come from: the card only, or also new characters in the story.

Looks are kept in this chat's state, never sent to the model. Predefined only: anyone not on file is described for that reply's pictures alone. Auto-harvest stores each new character's look once, even with images off.

Which LLM call writes a new character's look, with auto-harvest on. Off: no harvesting.

narrate is hidden while a POST call writes the pictures: it would find none.

narrate: the main reply describes each newcomer once, with no extra call. A POST call describes only newcomers, and their pictures wait for it. Set up POST calls under Extra LLM Calls.

stat_data object holding the cast. Blank: found by its present flag.

A leading stat_data. is optional. Naming it makes every member part of the cast, present flag or not. Cards without MVU ignore it.

Per-character field marking who is on screen. Blank: Is_present.

A true/false field on each character. While Roster collection is blank it finds the collection, and it always marks who is on screen. A card that renamed it and left this blank gets neither; the console says so.

Calls

Seconds before a stalled call is dropped. The other calls carry on.

5 to 600, default 60; a dropped call counts as empty. After the reply, POST gets one timeout per call in its longest queue. Past that, the reply is saved without POST.
